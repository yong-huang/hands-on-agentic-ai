## 三个量化结论

1. **换 harness 的收益与模型强度成反比**：强模型域 +0pp（3.8 下 bare=full，
   03/05/09 的"顺任务无差异"第四次应验）；弱模型域 **+40pp（1/10→5/10，
   ×5）**——harness 的价值在模型能力不足时被急剧放大。
2. **harness 不能无限弥补模型差距**：4b+full（5/10）仍远逊 3.8+bare
   （10/10）。"Agent = Model + Harness" 是乘法不是加法——两个因子都有
   下限。
3. **无效推理的成本证据**：4b 平均每任务烧 752 est token（3.8 的 11 倍）
   却只有 1/10 解决率——与论文"失败任务 token 是成功任务 2.7 倍"同构，
   预算止损（09）对弱模型不是优化是刚需。

## 系列主线的最终答案

**换 harness 与换模型作用于不同区间：模型决定上限，harness 决定下限——
并且 harness 的边际价值随模型变弱而放大。**"Harness AI vs Agentic AI"
的区别由此从概念变成一张自己跑出来的表。
