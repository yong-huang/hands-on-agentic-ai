# 25 · 越狱防护与 Guardrails

> 覆盖面试题：Agent 如何防止被诱导执行危险操作？护栏用规则约束还是模型判断？
> 双层护栏串联：规则层（关键词/正则硬特征，0 LLM 成本直接拦）+ 模型层
> （仅"可疑但没露馅"的请求进 LLM 分类器，fail-safe 解析失败即拦）。
> 测试集：10 条越狱尝试 + 10 条正常请求（含易误伤的教育性边界题）。

## 1. 运行与实测

```bash

python guardrails.py           # 真实: 可疑请求真的过 qwen3.8 分类器
```

真机实测（2026-09-09）：**越狱拦截 10/10，正常误伤 0/10**；全程模型层
仅 1 次调用（其余全被规则层 0 成本拦下）。

| 指标 | 结果 |
|:--|:--:|

| 正常误伤 | 0/10 ✓（含"反诈中心是做什么的"等边界题） |

## 2. 面试要点

- 分层串联：规则层拦特征明显的攻击（毫秒级、可解释）；模型层只复核
  灰区请求——全量走模型既贵又慢。
- fail-safe：分类器解析失败一律按拦截处理，宁可误伤不可漏放。
- 规则的软肋是变体绕过（谐音/编码），模型的软肋是成本与误伤——所以
  答案是"两层都要"，说出各自失败模式才是加分项。
