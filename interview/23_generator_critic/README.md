# 23 · Generator-Critic 辩论模式

> 覆盖面试题：多 Agent 协作什么时候比单 Agent 好？
> 20 道易错题（运算顺序/单位换算/经典脑筋题陷阱）三种模式对跑：
> direct（1 次调用）/ cot（1 次调用）/ debate（生成器起草 → 评审挑错 →
> 生成器修订，3 次调用）。答案可程序判定，输出正确率与成本对比。

## 1. 运行与实测

```bash
MOCK=1 python generator_critic.py    # 离线: 确定性模型, 20 题全量
python generator_critic.py           # 真实: qwen3.8, 6 道代表题
```

真机实测（2026-09-09，6 道代表题）：三种模式 6/6 全对（代表题上
qwen3.8 已是天花板，正确率拉不开）；成本差异如实呈现：

| 模式 | 正确 | 每题调用 |
|:--|:--:|:--:|
| direct | 6/6 | 1.0 |
| cot | 6/6 | 1.0 |
| debate | 6/6 | 3.0 |

离线 20 题全量（确定性难度模型）：direct 8/20 → cot 13/20 → debate
20/20，单调提升，辩论成本 3 倍。

## 2. 面试要点

- 辩论的价值在"可验证的易错任务"：评审 Agent 提供独立视角，修订能
  挽回初答的粗心错误；开放式创作任务收益趋零。
- 成本是"质量价格"：debate 每题 3 次调用换正确率——错误代价高的
  场景（下单/发邮件）才划算。
- 单 Agent + CoT 是强基线：多 Agent 打不过它就别上多 Agent——这道
  对比实验本身就是面试答案。
