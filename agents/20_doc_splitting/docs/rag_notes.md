# RAG 学习笔记

## 什么是 RAG

RAG（Retrieval-Augmented Generation，检索增强生成）让模型在回答之前先从外部知识库检索相关内容。它解决两个核心问题：模型的知识停在训练截止日，以及私有数据不在模型参数里。

RAG 的三个步骤是：切分文档并建立索引、按查询检索相关片段、把片段注入提示词后生成答案。检索质量决定了答案质量的上限。

## 切分的重要性

切分（Chunking）直接决定检索精度。切得太大，一个块里混入多个主题，检索时会带入噪音；切得太小，上下文不完整，答案缺乏依据。

常用的策略是递归字符切分：优先按段落边界切分，段落过长再按句子切，句子过长再按字符切。相邻块之间保留一定重叠（overlap），避免关键句被边界切断。

## 元数据

每个切分后的块都应携带元数据：来源文件、章节标题、块序号。检索命中后，元数据让答案可以引用出处，用户才能验证答案是否可信。
