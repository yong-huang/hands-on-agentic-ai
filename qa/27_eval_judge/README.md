# 27 · Agent 评测 Harness + LLM-as-Judge

> 20 任务双通道：可判定集（规则评分器 vs LLM-Judge 0/1，测一致率）+
> 开放集（仅 LLM-Judge，带 rubric 1-5 分）；偏见实验对同一答案换身份
> 标注（GPT-4 vs 7B 小模型）与换位置（A/B 对比顺序）。

## What

评测双通道 + 偏见探针：

- **可判定集**：规则评分器与 LLM-Judge 对跑，测一致率——能规则判定的
  绝不劳烦 Judge；
- **开放集**：仅 LLM-Judge，必须带 rubric（维度+分值定义），否则打分
  不可复现；
- **偏见探针**：同一答案换身份标注、换对比位置——"评测自己的评测器"。

心智模型一句话：**Judge 分数只做排序不做绝对结论——关键评测仍以规则/
人工为准。**

## Why

LLM-as-Judge 是开放任务唯一的规模化评测手段，但"Judge 可靠吗、偏见
有多严重"多数答案停留在背教条——身份偏差、位置偏差在自己的 Judge 上
是否存在，要实测复现或排除。

## How

```bash
cd qa/27_eval_judge
MOCK=1 python3 eval_judge.py    # 离线: 预置回答与评分 (偏见两种均复现)
python3 eval_judge.py           # 真实: qwen3.8 当 Judge (5 判定 + 2 开放 + 4 探针)
```

真机实测：

| 指标 | 结果 |
|:--|:--|
| Judge 与规则评分一致率 | **5/5 = 100%**（验收 ≥80% ✓） |
| 开放集 rubric 均值 | 4.0 |
| 身份偏差（GPT-4 vs 小模型） | 分差 0.0 · 未复现 |
| 位置偏差（A/B 换序） | 两次都选更优答案 · 未复现 |

两个反直觉发现：(1) qwen3.8 当 Judge 与规则完全一致——可判定任务上
Judge 是可靠的；(2) 两个经典偏见在真机 Judge 上都未复现（身份标注与
顺序不影响判断）——**偏见主要存在于小模型 Judge / 长列表对比场景**，
把"偏见存在"背成教条不如实测自己的 Judge。离线模式复现了两种偏差
（4.6 vs 3.4；A/B 换序翻转），验证了实验设计的可检测性。

## Deep Dive

**评测自己的评测器是一套方法**：拿同一答案换标签（身份探针）、换顺序
（位置探针）、注长答案（冗长探针），偏见存在就会复现、不存在就能排除
——比引用论文结论可靠。缓解手段：匿名化来源、随机化位置、多次取样取
均值。

## Q&A

**Q1: LLM-as-Judge 怎么设计才可靠？**

三条：只处理规则判不了的开放集；rubric 带维度与分值定义（否则打分不可
复现）；分数只用于排序比较，绝对结论交给规则评分或人工。
